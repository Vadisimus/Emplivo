Вигадані оголошення роботодавців · ДЕМО

Три вигадані роботодавці та шість повністю заповнених прикладів вакансій. Це не клієнти Emplivo і не справжні пропозиції роботи.

DEMO SPA-01 — вигаданий роботодавець

Вигадана мережа SPA-студій для демонстрації пошуку терапевтів і публікації вакансій. Компанія не є клієнтом Emplivo. Приклад запиту: шукаємо фахівців для таких вигаданих ролей: SPA-терапевт, Старший SPA-терапевт. Тестові контакти, не для зв’язку: hr@spa-01.example · +380000000001 · https://spa-01.example

DEMO FIT-02 — вигаданий роботодавець

Вигаданий фітнес-клуб із персональними та груповими заняттями. Створений лише як приклад оголошення роботодавця. Приклад запиту: шукаємо фахівців для таких вигаданих ролей: Персональний тренер, Тренер групових програм. Тестові контакти, не для зв’язку: hr@fit-02.example · +380000000002 · https://fit-02.example

DEMO WELL-03 — вигаданий роботодавець

Вигаданий wellness-центр для демонстрації управлінських вакансій та координації програм. Не приймає справжніх заявок. Приклад запиту: шукаємо фахівців для таких вигаданих ролей: Wellness-менеджер, Координатор wellness-програм. Тестові контакти, не для зв’язку: hr@well-03.example · +380000000003 · https://well-03.example
