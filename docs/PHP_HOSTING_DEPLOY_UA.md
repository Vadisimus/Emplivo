# Повна актуальна версія для PHP-хостингу

Ідентифікатор вихідної версії записано в `source-revision.txt`.
Пакет містить 108 сторінок українською, англійською та російською, каталог і
три вакансії Ever Tech, форму роботодавця, матеріали, PHP API та інструменти Telegram.
Демонстраційні вакансії й кабінети зберігають позначення демо.

## Розгортання

Розпакуйте ZIP **поза `www`**, наприклад у
`/home/emplivo/emplivo.com.ua/deploy-latest`, і запустіть у вашому SSH:

```bash
bash /home/emplivo/emplivo.com.ua/deploy-latest/deploy.sh
```

Ціль: `/home/emplivo/emplivo.com.ua/www`. Скрипт перевіряє контрольні суми,
PHP-синтаксис, шляхи, вільне місце та наявність приватної конфігурації бота.
Він зберігає повну копію `www` у приватному каталозі `deploy-backups` поруч із
`www`, потім замінює тільки файли пакета. Невідомі файли й завантаження залишаються
на місці. Вміст `.user.ini` зберігається. До чинного `.htaccess` додається лише
позначений блок вибору `index.html` перед `index.php`; старі директиви зберігаються.

`emplivo-private/config.php`, `emplivo-private/telegram.php`, ключі, черга Telegram
та `telegram-state` не входять до пакета. Контрольні суми приватної конфігурації
перевіряються без показу її вмісту. Наявний токен залишається на сервері.

Після встановлення перевіряються 28 вебадрес. Серед них головні сторінки трьох
мов, каталоги, деталі вакансій, форми роботодавця та файл перекладу. Скрипт також
перевіряє активну конфігурацію Telegram, ілюстрацію та PHP webhook.
Перевірки не створюють анкет і не надсилають тестових повідомлень.

Успішне завершення позначається `DEPLOY_OK`, далі вказується шлях резервної копії.
При збої встановлення або перевірки скрипт прибирає додані файли та відновлює
замінені файли з копії; результат — `DEPLOY_ROLLED_BACK`. Якщо відновлення
потребує ручних дій, він зупиняється з `ROLLBACK_NEEDS_ATTENTION` та шляхом копії.
Під час запуску не редагуйте ті самі файли сайту паралельно.

## Важливі залежності

- Для веб-PHP потрібні cURL і Sodium; чинна конфігурація перевірялася на PHP 8.5.12.
- Загальна форма CV на PHP-хостингу використовує окрему приватну конфігурацію
  Supabase у `emplivo-private/config.php`. Якщо її немає, звіт покаже
  `General application backend: NOT_CONFIGURED`; Telegram налаштований окремо.
- Неправильно оформлений наявний приватний `config.php` зупиняє розгортання
  до зміни публічних файлів, щоб уникнути показу його вмісту PHP API.
- Наявні правила доступу сервера залишаються чинними. Якщо вони не дозволяють
  нові сторінки або PHP endpoint, перевірка зупинить розгортання й поверне старі файли.
- Для обслуговування бота налаштуйте щогодинний запуск
  `php /home/emplivo/emplivo.com.ua/www/tools/telegram_admin.php cleanup`.

Не розміщуйте резервну копію чи розпакований пакет усередині `www`.
