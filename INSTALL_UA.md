# Встановлення актуальної версії Emplivo

Основні файли сайту знаходяться в корені цього репозиторію, не в папці www.
Див. README.md для GitHub Pages, локального перегляду та вимог PHP-хостингу.

На PHP-хостинг переносіть публічні файли з CHECKSUMS.json у кореневу папку
сайту (зазвичай www). У ній має бути index.html, а не www/www/index.html.
Збережіть чинні .htaccess і .user.ini. Папка emplivo-private з config.php
має залишатися поза публічним коренем і поза Git. Не завантажуйте .git,
приватні ключі, локальні налаштування або резервні копії у публічну папку.

GitHub Pages показує каталог і готує email-запити; PHP-шлюз працює тільки
на PHP-хостингу. Демо-заявки не надсилаються в базу.
