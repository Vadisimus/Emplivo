# Emplivo — Wellness Talent

Готовий двомовний сайт рекрутингової агенції SPA, Wellness та Fitness.
Головна сторінка `index.html` і публічні файли розміщені в корені репозиторію.

## Перегляд на GitHub Pages

Адреса: https://vadisimus.github.io/Emplivo/
У Settings → Pages використовується Deploy from a branch → main → /(root).
Файл .nojekyll вимикає зайву обробку статичного сайту. Шляхи підтримують
як корінь PHP-хостингу, так і префікс /Emplivo/ на GitHub Pages.

GitHub Pages не виконує PHP. У цій версії загальна анкета готує лист
на hr@emplivo.com.ua; користувач надсилає його сам і додає CV у поштовій програмі.
Сайт не повідомляє про збереження анкети в базі на GitHub Pages.
Демо-відгуки на вигадані вакансії завжди залишаються локальними.

## Редагування у VS Code

Відкрийте клоновану папку Emplivo. Основні файли:

- wellness.css — оформлення, адаптивність, типографіка й компоненти.
- wellness.js — маршрути, каталог, пошук, фільтри й форми.
- wellness-data.js — шість явно вигаданих прикладів вакансій.
- index.html, jobs/, employers/, en/ — готові статичні сторінки.
- assets/ — локальні ілюстрації, логотип і ліцензовані шрифти.
- api/applications.php — шлюз для реальної анкети лише на PHP-хостингу.

Для перегляду інтерфейсу підійде Live Server. Локальне надсилання у базу
потребує PHP-сервера та приватної конфігурації.

## PHP-хостинг

Потрібні PHP 8.3+ і cURL. Публічний корінь сайту має містити index.html,
api/ та assets/; приватна emplivo-private/config.php залишається поруч із
публічним коренем, поза репозиторієм. Приклад для розробки з кореня репозиторію:

```bash
php -S 127.0.0.1:8085 -t .
```

Публічні файли — 644, папки — 755. Для розгортання на хостингу зберігайте
чинні .htaccess і .user.ini. Файли приватних ключів і секрети не включено.
Телефон Emplivo: +380 (67) 777 80 60.

## Перевірки

Для браузерних перевірок потрібні Node.js, Playwright і Chromium:

```bash
node tools/verify_github_pages.cjs
# Із запущеним локальним PHP-сервером на 8085:
node tools/verify_wellness.cjs
```

Перевірено пошук, фільтри, сортування, збереження, UK/EN, мобільні екрани,
маршрути під /Emplivo/, підготовку email на Pages та PHP-відгук із
контрольованими відповідями API й повтором без дублювання. Реальні тестові
записи у робочу базу не створювалися.

Якщо сторінки повторно генеруються інструментами, виконайте
`python tools/make_portable.py` для відновлення відносних HTML-шляхів.
Скрипти збірки/пакування, що посилаються на /workspace, призначені для
хмарного середовища; згенерований сайт уже готовий до редагування без збірки.

## Межі функціональності

Усі вакансії та роботодавці-приклади позначені ДЕМО. Кабінети, pipeline й
сповіщення демонстраційні. Авторизація, email-розсилка, ATS, CMS, автоматичний
календар і реальні відгуки потребують окремих інтеграцій та перевірених даних.
На GitHub Pages загальна анкета працює через підготовку листа.
